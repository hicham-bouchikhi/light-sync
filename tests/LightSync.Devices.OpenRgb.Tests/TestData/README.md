# Recorded OpenRGB response

`controller-v4.bin` is an unmodified protocol 4 controller-data response from
[OpenRGB.NET's test fixtures](https://github.com/diogotr7/OpenRGB.NET/blob/master/src/OpenRGB.NET.Tests/TestData/08-Receive-RequestControllerData.bin).
It contains a keyboard controller with modes, zones and LED data. Its corresponding
recorded protocol-version response reports version 4. The payload starts with its
four-byte data size and does not include the network packet header.
